# Сборка Mega для CLC2 (Канада)

**Собрано 2026-07-31.** База — мастер (`../MAIN_BOARD_V5_COM5.ino`), то есть все
фиксы, накопленные с апреля. Единственное отличие от мастера — **калибровка
сервопривода мальчика возвращена под железо CLC2**.

## Почему нельзя лить мастер напрямую

В мастере стоит калибровка под DS3218, установленный на CLC3 (коммит 9abb1fa,
там прямо указано «do NOT OTA this hex to CLC1/CLC2»):

| Параметр | CLC3 (мастер) | **CLC2 (эта сборка)** |
|---|---|---|
| `boyServo.attach` | `(49, 500, 2500)` | `(49)` |
| `boyServo.write` (поворот) | `170` | `130` |
| `delay` в `start` | `1000` | `500` |

Серво поехало бы на 170° вместо 130° — с риском упереться в механику.

## Что проверено при сборке

- пины (`#define`) — идентичны мастеру;
- ленты `strip1=152`, `strip2=101` — идентичны;
- diff со мастером содержит **только** строки `boyServo` и один `delay`.

## Что даёт по сравнению с апрельской прошивкой клиента

- свободная RAM **3697** байт вместо 1933 (у апрельской компилятор ругался
  `Low memory available`);
- `galet1..galet5` вместо `galetG1..galetG5` — индикаторы галетников на пульте
  снова загораются (сервер обработчиков `galetG*` не имеет вообще);
- Restart после Ready открывает двери (`SendRestartToAll` + `OpenAll`);
- гейт тролля: следующий этап ждёт окончания рассказа;
- Owls guard, Owl Open Door в MapGame, Basket false-goal;
- WS2812: 5× clear/show против залипания ленты после reset Mega;
- дверь Баскетбола открывается после `story_56` (`basket_stage_open`).

## Обновление

При появлении новых правок в мастере — пересобирать этим же способом:
взять мастер, заменить `attach(49, 500, 2500)` → `attach(49)`,
`write(170)` → `write(130)`, `delay(1000)` → `delay(500)` в обработчике `start`.
